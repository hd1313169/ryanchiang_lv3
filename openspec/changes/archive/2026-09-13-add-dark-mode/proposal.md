## Why

The site currently only renders a light theme, even though its color palette is already fully tokenized (five CSS custom properties drive nearly all backgrounds, text, and borders). A dark mode toggle lets visitors read the portfolio comfortably in low-light conditions and is cheap to add given the existing token architecture — but it needs matching dark image assets and a small set of hardcoded colors fixed so the whole page (not just tokenized regions) responds consistently.

## What Changes

- Add a `data-theme` attribute on `<html>`, driven by a new dark color-token block in `tokens.css`.
- Add a floating, fixed-position theme toggle button (independent of the sidebar/nav layout) that flips `data-theme` between `light` and `dark`.
- Persist the user's explicit choice in `localStorage`; default to light when no stored preference exists (manual toggle only, no auto-following of `prefers-color-scheme`).
- Add an inline blocking script in `<head>` that applies the stored theme before first paint, to avoid a flash of the wrong theme.
- Replace the site's illustrations, case-study cover photos, and about-page portrait with theme-appropriate images: dark-mode variants are added as sibling files named with a `-dark` suffix (e.g. `content/cover-01-dark.jpg`), and a small wrapper renders both, switching visibility via `[data-theme="dark"]` CSS (same pattern already used by the two-frame sidebar illustration).
- Fix the ~7 hardcoded colors that currently bypass the token system (`about.astro`, `CaseStudyCard.astro`, `work/[slug].astro`) so they resolve correctly in both themes.
- Update the `<meta name="color-scheme">` tag to reflect the active theme instead of being hardcoded to `light`.

## Capabilities

### New Capabilities
- `theme-switching`: manual light/dark theme toggle, persistence, no-flash initial load, and theme-aware image swapping.

### Modified Capabilities
(none — `openspec/specs` has no existing capabilities yet; the underlying visual design system has not been synced from `build-portfolio-site` into main specs, so there is nothing to modify there.)

## Impact

- `src/styles/tokens.css` — new dark token block.
- `src/layouts/BaseLayout.astro` — inline no-flash theme script, `<meta name="color-scheme">`, mounts the toggle button.
- New `src/components/ThemeToggle.astro`.
- New `src/components/ThemedImage.astro` (wraps light/dark image pairs; illustrations continue using their existing two-frame pattern, extended with theme visibility).
- `src/components/Illustration.astro`, `src/components/CaseStudyCard.astro`, `src/pages/about.astro`, `src/pages/work/[slug].astro` — hardcoded color fixes and/or switch to `ThemedImage`.
- New dark-variant image assets: `content/cover-0{1..4}-dark.jpg`, dark variants of the two sidebar illustration frames, and an `about-hero-portrait-dark` image — supplied by the user, not generated by this change.
